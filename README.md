## 几个买之前要搞清楚的事

**IP 被墙怎么办？**

每 15 天可以免费申请换一次 IP。非被墙原因要换，收 $5。如果对这个需求特别频繁，加购 IP Care+ 服务可以缩短到每 7 天换一次。

**流量超了是不是直接关机？**

不是。不同系列有不同的降速策略——Eyeball 的 Tiny/Pocket 之类超量后降到 4Mbps，Tier 1 的 WEE 套餐降到 100Mbps，不会突然断。但 4Mbps 只适合 SSH 维护，跑业务就别想了。

**不超卖这件事是真的吗？**

DMIT 官方有不超卖的政策，所以热门套餐经常是真的没货，不是挂羊头卖狗肉那种假缺货。好处是你买到的性能是实打实的，坏处是你得蹲货——有时候补货几个小时就清空了。
